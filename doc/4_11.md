## **Vì sao tách đôi là đúng**

## **Khả thi kỹ thuật**

|                                 | After Effects        | Premiere Pro                                   |
| ------------------------------- | -------------------- | ---------------------------------------------- |
| Tạo file bằng script            | ExtendScript, `.aep` | ExtendScript hoặc UXP, `.prproj`               |
| Chạy headless bằng command line | Có (`-r script.jsx`) | **Hạn chế**, thường phải mở app và chạy script |
| Độ ổn định API                  | Tốt                  | Yếu hơn, ít tài liệu hơn                       |
| Có cách thay thế                | Không                | **Có**, xem bên dưới                           |

Cách thay thế cho Premiere là **không sinh `.prproj` trực tiếp**. Có 3 lựa chọn:

1. **Xuất FCP XML hoặc EDL / AAF** rồi import vào Premiere. Premiere hỗ trợ import tốt, và đây là lựa chọn mình khuyên. Python tự sinh file được, không cần mở Premiere, nên ổn định.
2. **ExtendScript trong Premiere:** dùng được (`app.project`, `sequence`, `importFiles`) nhưng hạn chế nhiều. Đặc biệt, Premiere không có API đầy đủ để chèn hiệu ứng.
3. **Sinh `.prproj` trực tiếp:** nên tránh. Đây là file XML nén gzip, cấu trúc rất phức tạp và dễ hỏng, giống vấn đề của `.aep`.

Kết luận: **Premiere nhận qua FCP XML, After Effects nhận qua JSX.**

Điểm cần quyết định là cách ghép shot AE vào Premiere:

- **Render shot AE ra video** (ProRes hoặc H.264, có alpha nếu cần). Cách này đơn giản, ổn định, và XML tham chiếu thẳng file đó. Mất tính chỉnh sửa trực tiếp nhưng vẫn có `.aep` để sửa và render lại.
- **Dynamic Link:** giữ được tính live, nhưng không tự động hóa tốt bằng script.

Mình khuyên dùng cách render. Bạn vẫn giữ `.aep` cho từng shot.

## **"Học mỗi ngày" thực chất là gì**

Không train model. Mỗi lần bạn làm xong một đoạn, hệ thống **lưu lại một bản ghi**:

```
json
```

{

"video": "Video1", "doan": 3,

Khi có đoạn mới, tool tìm 3–5 đoạn cũ giống nhất (RAG/few-shot) rồi đưa cho Gemini: "đoạn này bạn từng xử lý như sau, hãy làm tương tự." Dữ liệu càng nhiều, gợi ý càng đúng. Fine-tune chỉ nên cân nhắc khi bạn có hàng trăm đoạn.
