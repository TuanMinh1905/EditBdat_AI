Cập nhật 13/11/2026

Lưu và chọn key

  1. Nhập Gemini Key 1, Key 2 và OpenAI Key 3 nếu cần. Bấm Lưu cạnh từng ô; Đã lưu xác nhận key đã ghi trên máy và tự nạp lại khi mở app.
  2. Key đã lưu được khóa; bấm Chỉnh sửa để đổi. Bản chưa lưu chưa được dùng. Lưu ô trống để gỡ key đó.
  3. Tích Sử dụng cho các key muốn dùng; lựa chọn lưu ngay, áp dụng từ yêu cầu AI kế tiếp. Dùng được bất kỳ tổ hợp nào, kể cả chỉ OpenAI. Key 3 mặc định tắt.
  4. Sửa tối đa 8 model Gemini hoặc model OpenAI riêng rồi Lưu cài đặt. Mặc định Gemini theo ảnh quota: Flash 3.8 → 3.6 → 3 → 2.5 → Flash-Lite 3.5 → 3.1 → 2.5. OpenAI mặc định gpt-6.1-sol.

Luồng theo các ô Sử dụng

  • Chỉ Key 1: dùng các model của Gemini Key 1.
  • Chỉ Key 2: dùng các model của Gemini Key 2, bỏ qua Key 1.
  • Chỉ Key 3: dùng OpenAI ngay từ đầu, không gọi Gemini.
  • Key 1 + Key 2: Key 1 → Key 2.
  • Key 1 + Key 3: Key 1 → OpenAI, bỏ qua Key 2.
  • Key 2 + Key 3: Key 2 → OpenAI, bỏ qua Key 1.
  • Cả ba: Key 1 → Key 2 → OpenAI.
  • Không chọn key nào: báo cần bật key, không gọi API.

Mũi tên là chuyển khi lựa chọn trước không thể tiếp tục. Với Gemini, thử danh sách model trước khi chuyển key; lỗi mạng/server áp dụng retry bên dưới. Chỉ chọn một key thì khi key đó không thể phục vụ, app tạm dừng và thông báo, không tự dùng key đã bỏ tích. Key được chọn nhưng trống/chưa lưu cũng không dùng được; ví dụ chỉ bật Key 3 thì phải nhập và Lưu Key 3 trước.

Thứ tự dự phòng

  1. Thử hết model Gemini Key 1 → hết model Key 2 → OpenAI Key 3. Bỏ qua key tắt, trống và Gemini trùng.
  2. Quota/model không khả dụng: thử model kế trên cùng key. Quota 429 có cooldown riêng; bộ đếm token không phải quota còn lại.
  3. Mạng/timeout/server Gemini lỗi: thử lại một lần rồi sang key kế, tránh lặp mọi model trên server lỗi.
  4. OpenAI thành công thì làm tiếp hết lượt. Tắt Key 3 hoặc OpenAI lỗi thì thử Gemini còn bật.
  5. Mọi key đang bật đều lỗi: Source tạm dừng, thông báo và giữ kết quả. Sửa/lưu cấu hình rồi Continue. Tạo/preview/sửa timeline dừng và báo để chạy lại; không tự gửi lặp vô hạn.

Tiến độ và thống kê

  • Thông báo model/key hiện trên tiến độ Source và nhật ký. Chọn Key 1/2/3 ở thống kê để xem usage riêng.
  • Token ghi theo phản hồi thực tế; Reset chỉ xóa bộ đếm. MAX_TOKENS là giới hạn độ dài phản hồi, khác hết quota.
  • Kho ví dụ vẫn dùng khi chuyển provider. Không có Gemini embedding thì tìm theo từ khóa, không cần OpenAI embedding.
  • Hai key Gemini cùng project dùng chung quota. Google AI Pro không tự bảo đảm hạn mức API của app.
  • Kiểm tra After Effects và thư mục xuất trước khi tạo dự án. Sau đổi main/preload/backend cần đóng hẳn/mở lại; Ctrl+R chỉ nạp giao diện.
